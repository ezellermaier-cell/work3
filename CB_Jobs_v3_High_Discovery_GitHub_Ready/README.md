# CB Jobs v3 — High Discovery Futuristic Edition

This version fixes sparse job discovery.

## What changed
- Runs many targeted searches instead of one recent feed
- Searches for:
  - IT support
  - help desk / service desk
  - desktop support
  - systems administration
  - IT administration
  - technical support engineering
  - infrastructure
  - network administration / engineering
  - cloud support / administration
  - cybersecurity
  - security analyst
  - SOC analyst
  - incident response
  - Active Directory
  - Microsoft 365
  - Intune
  - endpoint / identity roles
- Uses six remote-job sources
- Jobicy: up to 200 jobs per keyword query
- Himalayas: multiple search pages per keyword
- Arbeitnow: multiple result pages
- Broader first-stage tech filter
- Lower default review threshold from 65% to 50%
- Lower Apply Queue threshold from 80% to 72%
- Deduplicates after collecting, not before searching
